# Measurements

Recorded measurement output, not facts derivable from source. Each run records its date, machine and configuration in
the accompanying text; use it as evidence of what was observed, not as a guarantee of current behaviour.

- [perf-baseline/README.md](perf-baseline/README.md) — S0 baseline and the S8/S10 ALSA and dummy-driver runs.
- [baseline-pc.md](baseline-pc.md) — the machine on which the baselines were recorded.
- [perf-baseline/s10/](perf-baseline/s10/) — raw latency, allocation and syscall logs for the S10 runs.

The interpretation of these numbers is in
[quality and validation](../developer/architecture/08-quality-and-validation.md).
