# 09 — Glossary

Terms as this code uses them. Where a historical document used a word differently, the code is the authority; the wire
and client-API fact sheets are [reference/protocol.md](../../reference/protocol.md) and
[reference/client-api.md](../../reference/client-api.md).

| Term | Meaning in jack2-mini | Source |
|---|---|---|
| **primary card** | The ALSA device whose clock, rate and period drive one server-wide graph; its failure stops the server. Named by ALSA id (for example `hw:CARD=PCH`), not by a changing card number. | [AlsaDriver.cpp](../../../server/drivers/alsa/AlsaDriver.cpp#L1608), [AlsaDriver.cpp](../../../server/drivers/alsa/AlsaDriver.cpp#L283) |
| **secondary card** | An additional ALSA device with its own PCM thread and rings, resampled to or from the primary clock. It occupies one of eight RT slots and can be retired without restarting the server. | [AlsaSecondaryCard.h](../../../server/drivers/alsa/AlsaSecondaryCard.h#L41), [AlsaDriver.h](../../../server/drivers/alsa/AlsaDriver.h#L44) |
| **graph cycle** | One execution of the shared graph: the driver waits for a period, copies capture into ports, `Engine::process` wakes clients in dependency order, then playback is copied out. Every client in the cycle sees the same `Cycle` values. | [Engine.cpp](../../../server/core/Engine.cpp#L185), [Client.hpp](../../../client/api/Client.hpp#L37), [04](04-runtime-view.md) |
| **activation count** | The live count of upstream clients a client is still waiting for. A signal decrements it; at zero the client is woken. It is deliberately outside the copy-on-write configuration state. | [ActivationCount.cpp](../../../ipc/memory/ActivationCount.cpp#L25), [GraphManager.h](../../../ipc/memory/GraphManager.h#L45) |
| **refnum** | The integer slot identifying a client in the engine's client table, `ClientControl`, synchro table and port ownership. The audio driver gets 0 and the freewheel driver 1. | [Engine.cpp](../../../server/core/Engine.cpp#L596), [ClientControl.h](../../../ipc/memory/ClientControl.h#L76), [Constants.h](../../../ipc/protocol/Constants.h#L55), [Constants.h](../../../ipc/protocol/Constants.h#L56) |
| **futex** | A kernel wait queue on a shared word. The engine signals a client by CAS 0→1 plus `FUTEX_WAKE_PRIVATE`; the client's RT thread claims it with CAS 1→0 or sleeps. | [LinuxFutex.cpp](../../../ipc/sync/LinuxFutex.cpp#L52), [LinuxFutex.cpp](../../../ipc/sync/LinuxFutex.cpp#L78) |
| **memfd** | An anonymous in-memory file created with `memfd_create`. The server creates one per control/graph/client-control segment and passes its descriptor to the client; there is no name registry to leak. | [ShmMem.cpp](../../../ipc/memory/ShmMem.cpp#L55), [FdSegment.cpp](../../../ipc/memory/FdSegment.cpp#L38) |
| **SCM_RIGHTS** | The Unix-socket ancillary-message type used to transfer those descriptors with the `ClientOpen` reply (and, for other messages, up to eight per message). Receivers use `MSG_CMSG_CLOEXEC`. | [FdSegment.cpp](../../../ipc/memory/FdSegment.cpp#L38), [Request.h](../../../ipc/protocol/Request.h#L388), [Message.h](../../../ipc/protocol/Message.h#L64), [FdSegment.cpp](../../../ipc/memory/FdSegment.cpp#L129) |
| **copy-on-write state** | `AtomicState<ConnectionManager>`: control calls mutate a private next state and publish it atomically; the RT thread reads the current state. Live activation counters are not copied. | [AtomicState.h](../../../ipc/memory/AtomicState.h#L122), [GraphManager.cpp](../../../ipc/memory/GraphManager.cpp#L110), [06](06-memory-and-sync.md) |
| **client control** | The per-client shared segment holding `ClientControl` (name, pid, refnum, UUID, callback mask and flags). It is the third descriptor in the `ClientOpen` reply. | [ClientControl.h](../../../ipc/memory/ClientControl.h#L47), [Request.h](../../../ipc/protocol/Request.h#L388) |
| **RT thread** | The thread allowed to run cycle work: the server's driver thread and each active client's process thread. In an RTSan build its functions carry `JACK_REALTIME_FN`. | [ThreadedDriver.cpp](../../../server/drivers/ThreadedDriver.cpp#L243), [ClientSession.cpp](../../../client/session/ClientSession.cpp#L828), [Realtime.h](../../../common/Realtime.h#L23) |
| **control thread** | Any thread that may block: the request listener, notification writers, and ALSA udev/control/reconfig workers. `LockedEngine` serialises their graph changes. | [SocketServerChannel.cpp](../../../server/ipc/SocketServerChannel.cpp#L206), [SocketNotifyChannel.cpp](../../../server/ipc/SocketNotifyChannel.cpp#L108), [LockedEngine.h](../../../server/core/LockedEngine.h#L57) |
| **freewheel** | A mode that runs cycles as fast as possible without the sound card; the driver is the freewheel driver, clock times follow cycles and `Cycle::m_freewheel` is true. | [FreewheelDriver.cpp](../../../server/drivers/FreewheelDriver.cpp#L30), [ClientSession.cpp](../../../client/session/ClientSession.cpp#L871), [Client.hpp](../../../client/api/Client.hpp#L42) |
| **PCM period** | The number of frames between interrupts on one ALSA stream. For a secondary card it is derived from `primaryBufferSize * rate / primaryRate`; `nperiods` is the number of periods in the hardware buffer. | [PcmCycle.hpp](../../../server/drivers/alsa/PcmCycle.hpp#L62), [AlsaSecondaryCard.cpp](../../../server/drivers/alsa/AlsaSecondaryCard.cpp#L205), [AlsaSecondaryCard.cpp](../../../server/drivers/alsa/AlsaSecondaryCard.cpp#L391) |
| **resampler** | A sample-rate converter created by `ResamplerFactory` and injected into a secondary card. `pipewire` is the only registered implementation; an unknown name is refused. | [Resampler.h](../../../server/drivers/alsa/resample/Resampler.h#L69), [Resampler.cpp](../../../server/drivers/alsa/resample/Resampler.cpp#L75), [Resampler.cpp](../../../server/drivers/alsa/resample/Resampler.cpp#L95) |
| **drift control** | The PI controller on a secondary card. It measures ring fill plus converter backlog, compares with a three-period target, and steers the resampler rate within ±1000 ppm with a 20e-6 slew limit. | [AlsaDriftController.h](../../../server/drivers/alsa/AlsaDriftController.h#L21), [AlsaDriftController.cpp](../../../server/drivers/alsa/AlsaDriftController.cpp#L49), [AlsaSecondaryCard.cpp](../../../server/drivers/alsa/AlsaSecondaryCard.cpp#L874) |
| **hot-plug** | udev monitoring of the `sound` subsystem. After a 250 ms quiet period the worker compares present devices with the desired secondary plan and adds or retires cards. | [AlsaHotplug.h](../../../server/drivers/alsa/AlsaHotplug.h#L42), [AlsaHotplug.cpp](../../../server/drivers/alsa/AlsaHotplug.cpp#L32), [AlsaDriver.cpp](../../../server/drivers/alsa/AlsaDriver.cpp#L948) |
| **xrun** | An ALSA overrun/underrun: the poll reports no usable frames. The cycle recovers and restarts, `kXRunCallback` is sent, and secondary resampler history is reset. | [PcmCycle.hpp](../../../server/drivers/alsa/PcmCycle.hpp#L50), [AlsaDriver.cpp](../../../server/drivers/alsa/AlsaDriver.cpp#L1159) |
| **port latency** | The client-supplied range stored on a `ServerPort` for one capture or playback direction. | [Client.hpp](../../../client/api/Client.hpp#L104), [ServerPort.h](../../../ipc/memory/ServerPort.h#L48), [Client.cpp](../../../client/api/Client.cpp#L428) |
| **total latency** | The server-computed latency of the longest path through a port, recomputed on request and read with `Client::totalLatency`. It is distinct from the port's configured range. | [Client.hpp](../../../client/api/Client.hpp#L132), [Client.cpp](../../../client/api/Client.cpp#L316), [Request.h](../../../ipc/protocol/Request.h#L88) |
| **driver module ABI** | The `dlopen` contract: one exported symbol `jackmini_driver_module`, a `Module` with version 1 plus `describe` and `initialize` function pointers, and fixed-size `DriverDesc` text fields. A wrong version, null descriptor or duplicate name is refused. | [DriverModule.h](../../../server/drivers/DriverModule.h#L33), [DriverLoader.cpp](../../../server/drivers/DriverLoader.cpp#L131), [DriverInterface.h](../../../server/drivers/DriverInterface.h#L123) |
